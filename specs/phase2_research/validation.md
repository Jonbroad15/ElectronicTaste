# Phase 2: Validation & Success Criteria

To successfully complete Phase 2, the following deliverables and validations must be met:

1. **Feature Extraction Proof of Concept**
   - We have successfully written a script that extracts at least 3 key features (e.g., BPM, spectral centroid) from a local audio file.
   - The extraction process is reasonably fast and can run locally.

2. **Reasoning Model Viability Test**
   - We have tested an LLM/reasoning model with structured audio data.
   - We have documented whether the LLM approach is accurate enough to pursue, or if we must rely entirely on a traditional ML classifier.

3. **Dataset Strategy Confirmed**
   - We have identified at least one viable dataset or a concrete method to gather training data for electronic subgenres.

4. **Architecture Decided**
   - We have a definitive answer to the question: *End-to-End Audio Classification vs. Feature Extraction + Reasoning Model?*
   - The `specs/tech.md` file is updated to reflect the final choices.
